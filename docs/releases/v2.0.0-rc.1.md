# QuizBee 2.0.0-rc.1

This release candidate separates the study interface, platform API, and background workers into independently runnable services. It preserves the legacy Express/MongoDB API as a separate compatibility image. Publishing these artifacts does not deploy a public application.

## Included

- Private study libraries, manual quiz creation, immutable quiz versions, nine question types, server grading, timed attempts and saved-answer recovery.
- Courses and assignments with membership checks, attempt limits, review policies, manual essay review and private question banks.
- A shared PostgreSQL job queue with worker roles, leases and retry controls; independent API replicas use shared sessions, rate limits and database time for assessment deadlines.
- Private local or S3-compatible material storage. Ingestion stages one private snapshot for scanning and extraction, preserving source labels and bounded parsing.
- Optional source-grounded generation through a configured OpenAI-compatible provider. The API can advertise worker capabilities without holding provider credentials.
- Docker images for the web interface, platform API, worker and legacy API, with health checks and runtime configuration. Local distributed Compose uses PostgreSQL, an authenticated SeaweedFS S3 service and Mailpit.

## Configuration and limits

No live AI provider is configured by the repository or this release. Generation requires operator-supplied provider settings on a generation worker; no simulated questions are substituted for provider output.

The local distributed setup explicitly permits unscanned development uploads. That setting is for local evaluation. Production ingestion fails closed without a working malware scanner. The extraction child has a restricted environment and resource limits, but it is not an operating-system sandbox.

Storage bucket policy, network protection, TLS, runtime secrets, backups and retention remain operator responsibilities. Use an unversioned material bucket with the current deletion interface; versioned-object and backup retention are not erased by application deletion. Interrupted uploads can leave unreferenced objects, and no automatic inventory reconciliation is included.

Legacy and platform data are separate. This release performs no automatic migration from MongoDB into PostgreSQL. Preserving legacy routes on the same browser origin is a compatibility arrangement, not a security isolation boundary.

This release candidate does not claim OCR, embeddings, institutional SSO, multi-organization administration, adaptive tutoring, or production deployment readiness. See the repository's [setup documentation](https://github.com/CSingh26/quiz-app/blob/v2.0.0-rc.1/docs/DEPLOYMENT.md), [storage notes](https://github.com/CSingh26/quiz-app/blob/v2.0.0-rc.1/docs/STORAGE.md), and [limitations](https://github.com/CSingh26/quiz-app/blob/v2.0.0-rc.1/docs/LIMITATIONS.md).
